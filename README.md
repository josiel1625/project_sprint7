# project\_sprint7

Proyecto para el sprint 7

https://project-sprint7-4.onrender.com/

Se revisó una base con información sobre vehículos usados condistintas características (tipo de vehículo, precio, kilometraje, condición, etc) con la finalidad de poder conocer más el producto y su situación actual para tomar distintos tipos de decisiones desde marketing, operativas o logísticas.

Esta aplicación permite explorar el dataset de anuncios de venta de vehículos usados. El usuario podrá analizar el histograma del odómetro y la dispersión de la distribución entre el precio y los distintos fabricantes de autos.
